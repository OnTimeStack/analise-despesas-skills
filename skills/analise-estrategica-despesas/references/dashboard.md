# Dashboard autocontido

Crie um único arquivo `analise_estrategica_despesas.html` sem dependências externas. Use CSS, SVG e JavaScript inline apenas quando agregarem valor.

Inclua:

1. período e qualidade dos dados;
2. total do período mais recente e divisão por categoria;
3. cobranças recorrentes pelo nome amigável aprovado, sinalizando possíveis duplicidades como itens a conferir;
4. parcelas ativas, valor futuro comprometido e liberações próximas;
5. tendências com a janela usada e alertas de crescimento acima de 50%;
6. plano de ação ordenado por impacto e esforço;
7. cenários conservador, moderado e otimista com as premissas exibidas.

Use formatação monetária `pt-BR`, bom contraste, layout responsivo e tabelas acessíveis. Use o nome amigável nos elementos do relatório; mantenha o nome original apenas quando necessário para auditoria. Não inclua dados pessoais além dos necessários para reconhecer uma cobrança.
